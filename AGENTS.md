# Hide iT repository

Commit each completed, verified game change and push it to the existing branch on `origin` at `https://github.com/dznati4/hide-it-game.git`. Check the remote and staged files before pushing. Use the configured Git identity or an explicitly identified Codex author for agent-authored commits.

The Characters PSX, PSX Asylum Kit, and Zenthrall City and Submarine sample licenses permit game use. Keep the local asset archives, imported third-party models, textures, and shaders out of Git and source exports. Document how to import them from the creators’ official downloads. Keep Unity caches, logs, and built players out of Git.
